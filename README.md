# The UK Economy Through Data: Trends, Relationships & Crises
A project looking at the UK economy using Python and SQL.

I used Python to clean and prepare the data, then PostgreSQL/SQL to analyse it.

The main indicators I explored at were:

- GDP, inflation, unemployment and wages over time
- Interest rates and inflation
- The relationship between unemployment and inflation
- 2008 Financial Crisis vs COVID-19

The analysis is presented in SQL, with a Power BI dashboard also being developed.

## Tools

Python · Jupyter · PostgreSQL · SQL · Power BI [coming soon]
